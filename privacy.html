개인정보처리방침

Entry Debugger는 엔트리 작품의 디버깅을 돕기 위해 필요한 정보를 사용자의 브라우저 안에서만 처리합니다.

시행일: 2026년 6월 6일

핵심 원칙: 확장이 읽는 작품 내용과 설정은 개발자 서버로 전송되지 않으며, 광고·분석·판매 목적으로 사용되지 않습니다.

1. 적용 범위

이 방침은 Chrome Web Store에서 제공되는 Entry Debugger(엔트리 디버깅 툴) 확장 프로그램에 적용됩니다.

2. 확장이 처리하는 정보

  • 엔트리 만들기 화면의 변수, 리스트, 신호, 장면, 함수와 블록 정보
  • 사용자가 디버깅 탭에서 직접 입력하거나 변경한 값
  • 기능별 활성화 상태와 이미지 저장 배율 같은 확장 설정

작품 정보는 사용자에게 디버깅 기능을 제공하기 위해 현재 페이지에서만 읽거나 수정합니다. 확장 설정은 Chrome의 storage.local에 저장됩니다.

3. 수집과 외부 전송

Entry Debugger는 작품 내용, 계정 정보, 사용 기록을 개발자 또는 제3자 서버로 수집하거나 전송하지 않습니다. 별도의 분석 도구, 광고 SDK, 원격 실행 코드도 사용하지 않습니다.

4. 이용 목적

처리되는 정보는 변수와 리스트 확인·수정, 신호 전송, 장면 이동, 함수 사용 위치 확인 등 사용자가 직접 요청한 확장 기능을 제공하는 데만 사용됩니다.

5. 보관과 삭제

  • 작품 정보는 확장이 별도로 보관하지 않습니다.
  • 확장 설정은 사용자가 초기화하거나 확장을 삭제할 때까지 브라우저에 남을 수 있습니다.
  • 디버깅 탭의 설정 초기화 버튼 또는 Chrome의 확장 프로그램 삭제 기능으로 저장된 설정을 제거할 수 있습니다.

6. 권한과 사이트 접근

확장은 기능 설정 저장을 위해 storage 권한을 사용하며, https://playentry.org/ws/* 형태의 엔트리 만들기 화면에서만 콘텐츠 스크립트를 실행합니다.

7. 제3자 제공과 판매

Entry Debugger는 사용자 데이터를 제3자에게 제공하거나 판매하지 않으며, 맞춤형 광고 또는 신용 평가에 사용하지 않습니다.

8. 외부 링크

확장 또는 소개 페이지에서 사용자가 직접 외부 링크를 열면 해당 사이트의 개인정보처리방침이 적용됩니다. 링크 이동 자체를 제외하고 확장이 외부 사이트로 작품 정보를 전달하지는 않습니다.

9. 방침 변경

기능 또는 데이터 처리 방식이 바뀌면 이 페이지를 갱신하고 시행일을 변경합니다. Chrome Web Store의 개인정보 공개 항목도 실제 동작과 일치하도록 유지합니다.

10. 문의

개인정보 보호 또는 확장 프로그램 관련 문의는 개발자 홈페이지 205.kr 또는 Chrome Web Store 지원 채널을 이용해 주세요.
