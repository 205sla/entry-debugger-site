개인정보처리방침

Entry Debugger는 엔트리 작품의 디버깅을 돕기 위해 필요한 정보를 브라우저에서 처리합니다. 사용자가 작품을 저장하면 준비한 썸네일은 엔트리 서버로 전송됩니다.

최종 수정일: 2026년 10월 4일

핵심 원칙: 확장이 읽는 작품 내용과 설정은 개발자 서버로 전송되지 않으며, 광고·분석·판매 목적으로 사용되지 않습니다.

1. 적용 범위

이 방침은 Chrome Web Store에서 제공되는 Entry Debugger(엔트리 디버깅 툴) 확장 프로그램에 적용됩니다.

2. 확장이 처리하는 정보

  • 엔트리 만들기 화면의 변수, 리스트, 신호, 장면, 함수와 블록 정보
  • 사용자가 디버깅 탭에서 직접 입력하거나 변경한 값
  • 기능별 활성화 상태와 이미지 저장 배율 같은 확장 설정
  • 사용자가 썸네일용으로 선택한 이미지·GIF·동영상과 브라우저에서 변환한 이미지(동영상 소리는 제외)
  • 사용자가 캡처를 요청한 실행 화면과 다운로드용 PNG
  • 커스텀 썸네일을 유지할 작품 ID와 작품별 유지 여부

작품 정보는 사용자에게 디버깅 기능을 제공하기 위해 현재 페이지에서만 읽거나 수정합니다. 일반 설정과 작품별 썸네일 유지 여부는 Chrome의 storage.local에 저장됩니다. 작품별 키는 thumbnailManager.project.<작품 ID>이며 값은 유지 여부입니다. 부스트와 프레임 프로파일러의 활성화 여부는 초기 실행에 반영하기 위해 엔트리 사이트의 로컬 저장소에도 기록합니다.

3. 수집과 외부 전송

Entry Debugger는 작품 내용, 선택한 미디어, 캡처 결과, 설정이나 사용 기록을 개발자 서버 또는 광고·분석 서비스로 전송하지 않습니다. 별도의 분석 도구, 광고 SDK, 원격 실행 코드도 사용하지 않습니다. 이미지·영상 변환과 실행 화면 캡처는 브라우저에서 이루어집니다. 파일을 선택한 것만으로 서버에 업로드하지 않습니다.

4. 이용 목적

처리되는 정보는 변수와 리스트 확인·수정, 신호 전송, 장면 이동, 함수 사용 위치 확인 및 미디어 변환, 썸네일 유지, 실행 화면 이미지 다운로드 등 사용자가 요청한 기능을 제공하는 데만 사용됩니다. 사용자가 엔트리에서 작품 저장을 실행하면 준비한 썸네일을 엔트리의 기존 HTTPS 업로드 경로로 전송합니다. 같은 작품의 커스텀 썸네일을 유지할 때는 썸네일 재업로드만 생략하며 작품 내용 저장은 엔트리가 처리합니다. 이 전송은 사용자의 엔트리 저장 요청에 따른 것으로 개발자 서버의 수집과 구분됩니다.

5. 보관과 삭제

  • 작품 JSON과 선택한 이미지·영상, 변환 결과를 확장 저장소에 보관하지 않습니다. 미리보기·적용 대기용 미디어는 페이지 메모리에서 일시적으로 처리하며 제거, 작품 이동, 기능 OFF 또는 페이지 종료 시 해제합니다. 저장 성공 후에도 임시 캡처 훅을 해제합니다.
  • 일반 설정과 작품별 유지 플래그는 해당 브라우저의 확장 저장소에 남습니다. 설정 초기화는 일반 기능 설정을 기본값으로 되돌리며, 저장한 커스텀 썸네일을 보호하기 위해 작품별 유지 플래그는 삭제하지 않습니다.
  • 작품별 기록은 해당 작품의 썸네일 관리자에서 제거를 눌러 삭제합니다. 다음 작품 저장부터 기본 썸네일로 변경됩니다. 기능 OFF만으로는 이 기록이 삭제되지 않습니다. Chrome에서 확장 프로그램을 삭제하면 확장의 로컬 설정과 모든 작품별 기록이 제거됩니다. 엔트리 사이트에 기록한 부스트와 프레임 프로파일러의 활성화 여부는 확장 삭제와 별개로 남을 수 있으며 해당 사이트 데이터 삭제로 제거할 수 있습니다.
  • 다운로드한 캡처 파일은 사용자가 직접 삭제합니다. 이미 엔트리에 저장된 작품·썸네일은 확장의 설정 초기화나 삭제로 제거되지 않으며 엔트리에서 관리합니다. 유지된 서버 썸네일의 미리보기를 열면 해당 이미지를 엔트리에서 불러옵니다.

6. 권한과 사이트 접근

확장은 일반 설정과 작품별 썸네일 유지 여부 저장을 위해 storage 권한을 사용하며, https://playentry.org/ws/* 형태의 엔트리 만들기 화면에서만 콘텐츠 스크립트를 실행합니다.

7. 제3자 제공과 판매

사용자가 요청한 엔트리 작품 저장에 필요한 전송 외에 사용자 데이터를 제3자에게 제공하거나 판매하지 않으며, 맞춤형 광고 또는 신용 평가에 사용하지 않습니다. 엔트리에 저장된 데이터에는 엔트리의 개인정보처리방침과 보관·삭제 절차가 적용됩니다.

8. 외부 링크

확장 또는 소개 페이지에서 사용자가 직접 외부 링크를 열면 해당 사이트의 개인정보처리방침이 적용됩니다. 링크 열기와 이 방침에 설명한 엔트리 작품 저장은 서로 별개의 사용자 동작입니다.

9. 방침 변경

기능 또는 데이터 처리 방식이 바뀌면 이 페이지를 갱신하고 시행일을 변경합니다. Chrome Web Store의 개인정보 공개 항목도 실제 동작과 일치하도록 유지합니다.
